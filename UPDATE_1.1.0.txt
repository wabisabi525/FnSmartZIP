# FnSmartZIP 1.1.0 更新说明

## 本次更新

- 修复大型压缩包解压时进度条更新不连续、最后直接跳到 100% 的问题。
- 兼容 Linux 版 7-Zip 的退格刷新输出，进度条会持续显示真实解压进度和当前文件。
- 状态查询调整为 250 毫秒一次，并禁用缓存，避免网页显示旧进度。
- 修复大型加密压缩包输入密码后长期停留在“正在验证...”的问题。
- 修复密码管理器在部分状态下无法打开的问题。
- 移除正式解压前重复的整包测试，缩短大文件解压前的等待时间。
- 普通压缩包和分卷压缩包均使用相同的后台解压和实时进度机制。

## 验证

- 使用 7,018,758,580 字节的加密 7Z 文件完成真实解压测试。
- 进度从 `0%` 连续更新至 `100%`，约 138 秒完成并成功输出文件。
- 自动化测试：195 项通过；失败、跳过和 Todo 均为 0。
- x86_64 与 ARM64 安装包均已完成发布审计。

## 发布文件

- `FnSmartZIP_1.1.0_search-fixed_x86_64.fpk`
- `FnSmartZIP_1.1.0_search-fixed_arm64.fpk`

两个安装包均保留搜索功能，内部应用标识相同，不能同时安装。
